02 / Architecture

A small QA system with deliberate boundaries.

Each layer exists to make failures reproducible, explainable and reviewable before anything reaches a real environment.

  1. 01
    QA Core

    Failure codes, evidence schema and retry decisions.

  2. 02
    Synthetic Fixture

    Local HTTP service with six deterministic fault modes.

  3. 03
    Integration + Browser

    Contract, Supertest and Playwright coverage on loopback only.

  4. 04
    Failure Injection

    Timeout, unhealthy, malformed, transient and lifecycle behavior.

  5. 05
    CI Evidence

    Validated JSON/Markdown artifact promoted into this static release.

03 / Safety boundary

The public surface is intentionally boring at runtime.

Vercel serves only static HTML, CSS, JavaScript and the frozen evidence snapshot. The synthetic fixture, failure modes and test execution remain local/CI concerns.
